\chapter{Solutions to the Exercises}
\label{sol:ch:solutions}

{\large\itshape The reference programs, exactly as they are in the repository.\par}

These are the reference implementations from the course repository. Every listing in this appendix
is typeset straight from its source file, whose path is printed above it, so what you read here is
what \code{make build} compiles; nothing has been retyped. The programs live under
\file{lectures/LNN/appendix/solutions}, each in its own directory with a Makefile that builds and
runs it with \code{make}, as described in \secref{c1:sec:makefile}. Most exercise sets are one
program each; where a chapter's sets build one program together, or two versions of one, its
section says so.

\textbf{Try each exercise before you read its solution.} A solution is one correct answer, not the
only one: where yours differs, compile both and compare the output with the one the exercise asks
for, and read the solution for the choices it makes that yours does not.
