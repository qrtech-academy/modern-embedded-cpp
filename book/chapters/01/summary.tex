\section{Review}
\label{c1:sec:review}

\needspace{6\baselineskip}
\subsection*{What you should be able to do now}
After this chapter, you should:
\begin{itemize}
  \item Be familiar with the modern C++ language features commonly used in embedded systems.
  \item Understand how C++ can improve structure and safety in embedded software.
  \item Understand how modern C++ structs can group data and behavior in a single type.
  \item Know how simple drivers can be implemented using modern C++ structs with member functions,
    constructors and destructors, and encapsulation.
  \item Understand how references simplify function interfaces compared to pointers.
  \item Understand how templates enable generic utilities such as bit manipulation helpers.
  \item Have an intuition for compile-time programming (\code{constexpr} and templates).
\end{itemize}

\needspace{6\baselineskip}
\subsection*{Questions to test yourself}
You should be able to explain:
\begin{enumerate}
  \item What is the purpose of \code{constexpr}?
  \item Why is \code{noexcept} often used in embedded systems?
  \item How does a C++ struct differ from a traditional C struct?
  \item Why are constructors and destructors useful in embedded C++?
  \item What is the purpose of making member variables private?
  \item What advantages do references have compared to pointers?
  \item Why can templates increase binary size in embedded systems?
  \item What are parameter packs used for?
\end{enumerate}
