\section{Review}
\label{c3:sec:review}

\needspace{6\baselineskip}
\subsection*{What you should be able to do now}
After this chapter, you should:
\begin{itemize}
  \item Be able to create classes that inherit from other classes.
  \item Be able to create interfaces.
  \item Understand how several different implementations can be used through the same interface.
\end{itemize}

\needspace{6\baselineskip}
\subsection*{Questions to test yourself}
You should be able to explain:
\begin{enumerate}
  \item What does inheritance mean in C++?
  \item What is an abstract class?
  \item Why can it be useful to use an interface for a driver?
\end{enumerate}
